# Dating Application

A full-stack dating web application built with **ASP.NET Core Web API** and **Angular**.

The application implements user authentication, profile and photo management, member discovery, likes, private messaging, and real-time online presence.

## Tech Stack

- **Backend:** ASP.NET Core Web API, C#, Entity Framework Core
- **Frontend:** Angular, TypeScript
- **Authentication:** JWT
- **Database:** SQLite / SQL Server
- **UI:** Tailwind CSS, DaisyUI
- **Object Mapping:** AutoMapper
- **Real-time Communication:** SignalR

## Key Features

- User registration and authentication
- JWT-based authorization
- Protected Angular routes
- User profiles and profile management
- Photo upload and gallery management
- Like functionality
- Member filtering, sorting, and pagination
- Private one-to-one messaging
- Real-time messaging using SignalR
- Real-time online presence
- Angular notifications
- Template-driven and Reactive Forms
- Client-side and API error handling

## Application Structure

The solution is organized into separate backend and frontend applications:

- **API** — ASP.NET Core Web API
- **Client** — Angular single-page application
- **Docs** — Project documentation

## Project Context

This project was developed as part of a practical **ASP.NET Core and Angular** course and implemented incrementally from the initial project setup through the core application features.

The application demonstrates practical experience with **RESTful APIs, Entity Framework Core, JWT authentication, Angular application development, data filtering and pagination, photo management, and real-time communication using SignalR**.
