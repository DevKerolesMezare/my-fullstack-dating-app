# Full-Stack Dating App

A learning project built while following the **Build an App with ASP.NET Core and Angular from Scratch** course.

The application allows users to create profiles, manage photos, like other users, and exchange private messages in real time.

## Tech Stack


### Backend

- ASP.NET Core Web API
- Entity Framework Core
- ASP.NET Core Identity
- JWT Authentication
- SignalR
- SQLite during development
- SQL Server in the final setup


### Frontend

- Angular
- Tailwind CSS
- DaisyUI


## Features

- Authentication and authorization
- User profiles
- Photo management
- Likes
- Private messaging
- Filtering, sorting, and pagination
- Real-time messaging and online presence


## Status

The course implementation is complete.
